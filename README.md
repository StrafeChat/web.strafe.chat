## Usage

## Node Setup

```bash
$ npm install # or pnpm install or yarn install
```

## Available Scripts

In the project directory, you can run:

### `npm run dev`

Runs the app in the development mode.<br>
Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

### `npm run build`

Builds the app for production to the `dist` folder.<br>
It correctly bundles Solid in production mode and optimizes the build for the best performance.

The build is minified and the filenames include the hashes.<br>
Your app is ready to be deployed!

## Bun Setup (Recommended)

[Bun](https://bun.sh) is a fast all-in-one JavaScript runtime. It's designed to be used for modern JavaScript development, but it also has a large ecosystem of libraries and tools that you can use.

To get started, install bun:

```bash
bun install
```

### Learn more on the [Bun Website](https://bun.sh)
